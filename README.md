# Руферский бот

Игровой Telegram-бот: виртуальные вылазки, очки, уровни, рейтинг, усиления за Stars, промокоды и события.

## Запуск

Python 3.12+.

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# Вставьте токен в BOT_TOKEN в файле .env
python main.py
```

Дополнительные переменные: `ADMIN_ID`, `TEST_ID`, `DATABASE_URL` (по умолчанию `sqlite+aiosqlite:///db.sqlite3`). Запускайте из корня проекта, чтобы использовать прежнюю базу. Перед обновлением сохраните её копию. Существующие таблицы и данные пользователей сохраняются; справочники дополняются без удаления записей. Файл `.env` из корня проекта загружается автоматически. Вставьте токен в строку `BOT_TOKEN=...`; переменные окружения имеют приоритет. `.env` исключён из Git, шаблон настроек — `.env.example`.

## Структура

- `bot/routers/` — игровые, административные и платёжные обработчики.
- `bot/services.py` — транзакция игровой вылазки.
- `bot/messages.py`, `bot/keyboards.py` — оформление.
- `bot/common.py` — общие проверки и доставка сообщений.
- `bot/config.py`, `bot/catalog.py` — настройки и справочники.
- `database/base.py`, `database/requests.py` — модели и операции SQLite.

Команды игроков: `/start`, `/roof`, `/me`, `/top`, `/level`, `/buy`, `/promo КОД`.
Администратор управляет ботом через инлайн-кнопки в личном чате. Открыть панель: `/start` или `/admin`.

Стандартные усиления действуют 24 часа; у созданных администратором срок задаётся отдельно. Минимальный интервал вылазок — 10 минут. Выключенные события не влияют на игру. Тестовый игрок сохраняет прежнее особое поведение: без ожидания и накопления очков.

Проверки: `.venv/bin/python -m unittest discover -s tests -v`. Тесты используют отдельную базу в памяти. Реальные Telegram-платежи и рассылки тестами не выполняются.

## Админ-панель и временные предметы

Отправьте `/start` или `/admin` боту **в личном чате** с аккаунта `ADMIN_ID`. Дальше выбирайте действия инлайн-кнопками. Значения вводятся обычными сообщениями в ответ на подсказки. На шагах ввода есть кнопка отмены; кнопка «В меню» возвращает панель и сбрасывает незавершённый ввод. `/cancel` также возвращает меню.

| Раздел | Действия |
| --- | --- |
| Предметы | Просмотр карточек, скрытие и включение в магазине |
| Создать предмет | Пошаговый ввод параметров и подтверждение |
| События | Название, описание, КД, риск, уровень, запуск, остановка, просмотр и сброс настроек |
| Сводка | Количество игроков, чатов, предметов и промокодов |
| Каналы | Список подписок, добавление или обновление по ID, удаление, восстановление стандартного канала с подтверждением |
| Промокоды | Создание кода, лимит активаций, награда, подтверждение сохранения |

Для канала укажите числовой ID вида `-100…`, название и ссылку `https://t.me/…`. Боту нужны права для проверки подписки. Промокод может содержать 1–32 латинские буквы, цифры, `_` или `-`; регистр приводится к верхнему. Существующий промокод не перезаписывается.

Прежние команды `/event`, `/channel` и `/add_promo` оставлены для совместимости; для работы через панель вводить их не требуется.

«Создать предмет» запускает пошаговый мастер с проверкой значений и подтверждением перед сохранением. Задаются название, описание, цена, сокращение отдыха, снижение риска в процентных пунктах, бонус подбора объектов и два независимых срока:

- **Действие покупки**: 1–8760 часов с момента покупки.
- **Продажа**: 1–8760 часов с момента создания или 0 — бессрочно.

В разделе предметов можно скрывать и включать товары. Включение не продлевает истёкший срок продажи. Скрытие и истечение продажи не отменяют уже купленные усиления. Старые счета на недоступные товары отклоняются до оплаты. Параметры созданного товара неизменяемы, чтобы не менять условия уже оплаченных покупок; для другого предложения создайте новый предмет с другим названием.

В `STANDARD_ITEMS` добавлены разводной ключ (+1 к подбору объектов) и рюкзак (КД −5 минут), по 10 Stars каждый. Старые предметы сохраняют действие 24 часа. При запуске новые поля добавляются в существующую SQLite-базу автоматически; перед обновлением сделайте резервную копию.
